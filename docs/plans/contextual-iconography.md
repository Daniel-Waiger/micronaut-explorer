# Contextual microscopy iconography

The previous icon system made a generic SaaS structure clearer, but several
symbols still described a design tool rather than a microscopy-planning tool.
This pass maps the visual language to the user's actual workflow:

| Surface | Icon concept |
| --- | --- |
| Product mark / Microscopy | Microscope |
| Home | Workspace dashboard |
| Project | Searchable research brief |
| Study | Laboratory flask |
| Design | Experimental controls |
| Naming | Sample tag |
| Overview | Connected study map |
| Guide | Open reference book |

The icons remain inline thin-stroke SVGs. This keeps the app zero-dependency
and allows the existing single-file build to ship the complete visual system.
